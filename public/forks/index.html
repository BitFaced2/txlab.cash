THE BITCOIN FORK TREE

Every fork · every reason · 2009 – 2026

What this is

A subway-map of Bitcoin's entire family tree: every chain split, code fork, protocol upgrade, accidental fork and failed campaign. Solid lines share Bitcoin's ledger history up to their fork block. Dashed lines copied the code but started a new genesis — ancestry, not shared history. Round stations are soft forks; diamonds are hard forks.

✔ Verified on my own nodes

Events wearing the green badge were confirmed directly against the author's own full nodes — Bitcoin Core 28.1 (BTC) and Bitcoin Cash Node 29.0 (BCH) — by pulling each block at its documented height and checking its timestamp and hash (August 2026). No explorer APIs, no trust required. BCH's scheduled-upgrade activation blocks were computed the hard way: binary-searching the BCHN chain for each upgrade's median-time-past crossing — the method reproduced both known split heights exactly.

A lesson learned doing it: block height alone is ambiguous across forks — BCH ran ahead of BTC after its 2017 difficulty changes, so the same height lands on different dates on each chain. Every height on this map is paired with its chain.

⚠ Honesty flags

Entries wearing the amber badge rest on secondary sources only (several 2017-18 airdrop coins barely documented anything). Dead-line endpoints are approximate — most of these coins faded rather than announced a death. BCH codenames after Axion (2020) are community nicknames, not official.

What's deliberately missing

Monero, Ethereum, Ripple, Cardano and friends — commonly mislabeled as Bitcoin forks; they are independent codebases. Vaporware forks that never demonstrably launched (Bitcoin Silver, Bitcoin Uranium) are excluded. BIP-110 stays off the map until it actually activates or splits.
